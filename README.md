# Пульт БДР — сравнение режимов работы завода

Веб-пульт сравнения пяти режимов переработки: ядро ↔ масло, подсолнечник
и рапс. Отвечает на один вопрос — **какой режим ставить и почему**.

Расчёт перенесён из книги «БДР (мотивация).xlsx» построчно, у каждой формулы
указана ячейка-источник. Сходимость с книгой проверена по 143 ячейкам
и тремя контрольными наборами.

> **Публичный репозиторий и публичный сайт, без авторизации.** Контрактные
> цены, ставки логистики, пошлины, цены закупа и структура себестоимости
> находятся в открытом доступе осознанно. Управленческий ФОТ вынесен
> в параметр и в репозитории отсутствует: вводится в браузере и хранится
> только там. Подробно — [ОГРАНИЧЕНИЯ.md](ОГРАНИЧЕНИЯ.md) §9.

---

## Быстрый старт

```bash
cd app
npm install
npm run dev          # http://localhost:5173
```

Проверки — те же, что гоняет CI:

```bash
cd app
npx vitest run       # 68 тестов: эталоны A, B, C, блокировки, сторожа, живой пересчёт
npx tsc -b --noEmit
npm run lint
npm run build
```

## Устройство

```
app/src/domain/   расчёт и типы. Ни React, ни сети, ни браузерных API —
                  это условие проверяемости эталонов
app/src/data/     входные параметры, наборы моделей, эталоны, сборка
app/src/screens/  Сравнение · Карточка режима · Ставки и курсы · Сценарии
app/tests/        регрессия: эталоны A, B, C, блокировки, сторожа
```

Правило зависимостей: `screens → components → domain`. Обратных стрелок нет.

## Что пульт делает и чего не делает

**Делает.** Считает пять режимов на месячной базе, показывает раскладку
тонны сырья, выбирает лучший базис для М1 и показывает расстояние
до переключения, раскрывает каждый итог формулой со ссылкой на ячейку книги,
останавливает расчёт по графу зависимостей, когда параметр просрочен
или не задан.

**Не делает.** Не подтягивает пошлины МСХ автоматически (гео-ограничение),
не пересчитывает сценарии ползунками (заглушка, выдуманных цифр нет),
не показывает годовые итоги (в книге они не сходятся сами с собой),
не подставляет оценок там, где в БДР данных нет.

Подробно — в [ОГРАНИЧЕНИЯ.md](ОГРАНИЧЕНИЯ.md).

## Исходные данные

Книга БДР, её снимки, выгрузки и вспомогательные скрипты сверки
**в репозиторий не входят** — закрыты `.gitignore`. Книга открывается
только на чтение.

## Публикация

Пуш в `main` → GitHub Actions: типы → линт → тесты → сборка.
**Если эталоны разошлись, дальше не идём.**

Дальше — сборка и публикация на GitHub Pages.

Локальный просмотр собранного сайта: `cd app && npm run build && npm run preview`.

## Секреты

Их нет. Мосбиржа и ЦБ РФ — публичные источники без ключей, пошлины МСХ

во фронтенде быть не должно.
