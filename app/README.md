# Пульт БДР — сравнение режимов работы завода

ЭТАП 4: формулы перенесены. React + TypeScript + Vite + Recharts.

## Запуск

```bash
cd app
npm install
npm run dev      # http://localhost:5173
```

Сборка и локальный просмотр:

```bash
npm run build    # tsc -b && vite build → dist/
npm run preview  # http://localhost:4173
```

Тесты, типы, линт:

```bash
npx vitest run     # 45 тестов: эталоны A, B, C, граф блокировок, проводка
npx tsc -b --noEmit
npm run lint
```

## Что уже есть и чего ещё нет

**Есть:** расчётное ядро — формулы строк 9–41 перенесены из БДР, у каждой
в комментарии указана ячейка-источник. Все экраны, дизайн-система, «Раскладка
тонны», курсовая линейка М1, модуль пошлин с блокировкой по графу зависимостей,
цепочка CZCE, раскрытие формул со ссылками на «лист!ячейка», адресация по хэшу.

**Нет:** пересчёта сценариев — ползунки показывают форму экрана и явно помечены
заглушкой. Выдуманных цифр нет.

### Проверка переноса

| Что | Результат |
|---|---|
| Эталон A «как в Excel» | 5 моделей × 7 показателей — сходится |
| Эталон B (C5 = 1, НДС 1,2) | 3 модели × 3 показателя — сходится |
| Эталон C (рабочий, НДС 1,22) | 7 строк × 7 показателей — сходится |
| Сверка со снимком книги | **143 ячейки, 0 расхождений** |
| Всего тестов | 45 |

Допуск: 0,011 тыс.₽ по деньгам, 0,0001 по доле рентабельности. Он покрывает
только то, что эталоны в ТЗ напечатаны округлёнными до копеек.

### Структура ядра

```
domain/yields.ts     выходы: F2 = 1−F1−F3−F4, F6 = (1−потери)−F5, баланс массы
domain/pricing.ts    нетбэк, два типа пошлины, цепочка CZCE, формулы файла B1..B6
domain/basis.ts      выбор базиса M1, порог выводится формулой (сверх БДР)
domain/engine.ts     строки 9–41
domain/formulaMap.ts показатель → формула → «лист!ячейка»
domain/validation.ts блокировки ПО ГРАФУ зависимостей, не по списку моделей
```

### Блокировки — по графу, а не по списку

Модель останавливается тогда и только тогда, когда не задан или устарел
параметр, который **фактически входит в её расчёт**:

| Параметр | Кого блокирует |
|---|---|
| ставки МСХ (подсолн. масло и жмых) | М2, М5 |
| экспортная пошлина 6,5 % (ядро, П/Ф, 3 кат) | М3, М5 |
| курс USD | М1 (иранский базис) |
| курс CNY | все |

М5 потребляет обе группы пошлин → блокируется по любой. М3 по ставкам МСХ
**не** блокируется: подсолнечник у неё сырьё на входе, а ставка МСХ применяется
к продукту на выходе. Заблокированная модель называет конкретный параметр.

### Канонический вход по М4

Цена контракта 8 000 CNY/т — её фиксирует эталон (C). Котировка CZCE
**выводится** из неё обратной цепочкой (9 781,43) и служит проверкой попадания
в реальный диапазон. Подстановка округлённой котировки как входа даёт контракт
8 000,0022 и сдвигает фин. результат М4 на +0,017 тыс.₽ — поэтому канон именно
контракт. Сторожит тест `wiring.test.ts`.

## Структура

```
src/
  domain/     чистая предметная область: типы, форматирование и весь расчёт.
              Ни React, ни сети, ни браузерных API — это условие
              проверяемости эталонов A, B, C
  data/       входные параметры (контракты, ставки, логистика, курсы),
              пять наборов параметров моделей, эталоны, сборка результатов
  components/ Ribbon (раскладка тонны), BasisRuler, bits (значки, панели)
  screens/    Comparison, ModelCard, Rates, Scenarios
  theme/      tokens.css (цвет, шрифты, формат чисел), app.css (раскладка)
```

Правило зависимостей: `screens → components → domain`. Обратных стрелок нет.

## Условия рабочего расчёта

Эталон (C): прогнозного дисконта нет (C5 = 1), НДС услуг 22 %, курс CNY 11,5000,
USD 80,00, пошлины подсолнечника — реконструкция из файла (масло 7 000,00 ₽/т,
жмых 1 015,91 ₽/т).

Источник данных: «БДР (мотивация).xlsx», снимок `SNAPSHOT-2026-08-03.xlsx`
(права 444), только чтение.

## Договорённости, зашитые в интерфейс

- Удельные показатели считаются **на тонну сырья** (`L1 × N1`), никогда
  на строку 9 «Продажа, т»: в М2 и М5 туда попадает полуфабрикат, который
  не продаётся.
- Лента раскладки **всегда одной ширины** = 1 тонна сырья, независимо
  от захода. Масштаб живёт в отдельной колонке.
- Пустая ячейка ≠ ноль. «Не задано» и «задано нулём» — разные состояния.
- Цвет никогда не единственный маркер: у каждого статуса значок и слово.
- Отличия от файла показываются флагом и подписью, молча не «чинятся».
- Новая функциональность поверх БДР помечается значком «➕ сверх БДР».
- Прогнозный дисконт доступен **только** в блоке сценариев.

## Шрифты

Golos Text (текст и заголовки) + IBM Plex Mono (все числа, `tabular-nums`).

Пульт МЭЗ Бийск использует Chakra Petch, Hanken Grotesk и Bricolage Grotesque —
**ни один из них не содержит кириллицы**, поэтому русский текст там подставляется
системным шрифтом. Здесь весь интерфейс русский, поэтому взят Golos Text;
IBM Plex Mono сохранён как домашний шрифт цифр.

## Секреты

Их нет. MOEX ISS и ЦБ РФ — публичные источники без ключей. Пошлины МСХ вводятся
руками. Во фронтенде не должно появляться ни ключей, ни токенов.
